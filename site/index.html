412 fictional offers. The default threshold, 60, is the real one.

Five layers between an offer and a send.

  1. POSTING

    A public listing, read from the board’s own feed. Duplicates and excluded companies are dropped first.

  2. SCORE

    One number from six weighted factors: fit 30, stability 20, pay 15, learning 15, interview style 10, other 10. Below 60 the offer stays out of the queue.

  3. CV

    My master CV is reordered for the posting and gets one added sentence. It can only use skills already on it.

  4. ANSWERS

    Known answers come from a file I wrote. A question with no answer is left blank, never guessed.

  5. GATE

    Every send is a dry run until I approve it. Live mode sends only what is approved.
